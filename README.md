# glass-notes-kitten
带桌面颜文字小猫的透明玻璃风格便签工具
小猫长这样：ᓚ₍ ^. .^₎


## 功能

### 便签

- 透明玻璃拟态界面，深浅两套主题
- 三个页签：**待办 / 笔记 / 已完成**，默认打开待办
- 每条记录前有红黄绿圆点表示优先级，红色置顶；点击圆点可随时改
- 待办带勾选框，勾上自动划掉并移入「已完成」；在已完成页再点一下可恢复
- 输入框支持 `@时间` 快捷语法，到点小猫会举牌提醒（见下）
- 底部「数据」可打开数据文件夹或导出备份

### 颜文字小猫

- 平时蹲在桌面角落，可自由拖动到任意位置
- 左键点击随机播放：玩毛线球 / 喵喵叫 / 追蝴蝶 / 唱歌 / 爱你
- 右键菜单：吃饭 / 休息
- 23:00–7:00 自动进入睡觉状态
- 存在未完成的红色待办时，小猫前面会出现红色感叹号
- 便签底部「小猫」按钮可显示 / 隐藏

### 窗口与托盘

- 点 ✕ 收进系统托盘（任务栏不显示），提醒照常工作
- 托盘右键：打开便签 / 显示小猫 / 打开数据文件夹 / 导出备份 / 退出
- 便签的位置、大小和小猫的位置都会被记住，下次打开原样恢复

## 到点提醒怎么用

在待办输入框里直接写时间，保存后文字里的时间标记会自动去掉：

| 输入示例 | 提醒时间 |
| --- | --- |
| `写周报 @20:30` | 今晚 20:30（时间已过则算明天） |
| `开会 @10分钟后` | 10 分钟后 |
| `取快递 @2小时后` | 2 小时后 |
| `交材料 @明天9:00` | 明天 9:00 |

到点后小猫头顶弹出牌子：

> **[写周报]** ᓚ₍ ^. .^₎

- 点一下牌子或等 6 秒自动收起
- 多个同时到点会显示最近的一条，并标注 `+2`
- 睡觉时段（23:00–7:00）到点的提醒不弹牌，早上 7 点后统一补上

> **注意**：提醒依赖程序正在运行。从托盘右键选「退出」、或关机重启后没有重新打开，到点就不会举牌。目前没有开机自启，需要每天手动启动一次。

## 数据

数据保存在 `%APPDATA%\glass-notes`：

```text
%APPDATA%\glass-notes
├── glass-notes-data.json       全部记录
├── glass-notes-data.json.bak   上一次保存的自动备份
└── ui-state.json               窗口位置
```
